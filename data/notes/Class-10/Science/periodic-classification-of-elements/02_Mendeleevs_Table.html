Mendeleev's Periodic Table

Mendeleev arranged elements by increasing atomic mass, with similar properties in columns.

Mendeleev's Periodic Law

Properties of elements are periodic function of their atomic masses.

Features of Table

  • 63 elements in 8 groups, 7 periods
  • Groups: Vertical columns
  • Periods: Horizontal rows
  • Gaps for undiscovered elements

Merits

  • Predicted eka-aluminium (Ga), eka-silicon (Ge)
  • Corrected atomic masses

Anomalies

  • Position of isotopes
  • Some heavier before lighter (Te, I)

💡 Insights for Inquisitive Minds

Mendeleev's bold predictions validated his law. He prioritized properties over strict mass order, showing scientific intuition.
